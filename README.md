# CRUD de Tareas - Implementación con Git Flow

Este proyecto consiste en una aplicación web simple tipo To-Do List que permite gestionar tareas mediante operaciones CRUD (Crear, Leer, Actualizar y Eliminar).

El objetivo principal es aplicar correctamente la estrategia de control de versiones **Git Flow**, incluyendo el uso de ramas, commits estructurados y Pull Requests.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage (persistencia de datos en el navegador)

---

## Estrategia de ramas (Git Flow)

El proyecto sigue la estructura clásica:

- `main` → Producción
- `develop` → Integración de features
- `qa` → Pruebas y validación

---

## Features implementadas

Se desarrollaron 5 funcionalidades principales, cada una en su propia rama:

- `feature/project-setup`
- `feature/add-task`
- `feature/list-tasks`
- `feature/edit-task`
- `feature/delete-task`

---

## Pull Requests

Se realizaron un total de **15 Pull Requests**, distribuidos de la siguiente manera:

- Cada feature fue integrada en:
  - `develop`
  - `qa`
  - `main`

**Total:**
5 features × 3 ramas = **15 PRs**
